# Per-user curriculum lifecycle

Generates validated curriculum DAGs from a minimized synthetic profile slice and an injected reviewed source/template registry. Subject knowledge lives in registry data, not code branches. Placement is optional, bounded, uncertainty-aware, expiring, and correctable. Authority-gated corrections can change only minimized goals and access routes. Invalid/ungrounded output becomes a reviewed fallback or human-planning gate. Revisions preserve immutable ancestry and explicit change sets; split/merge/supersession never transfers mastery silently.
