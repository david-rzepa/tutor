# Evidence-based learning design

This directory is the durable research layer for agents designing the tutor. It optimizes for **durable, transferable mastery per unit of learner time**, subject to privacy, safety, accessibility, and age-appropriate design.

There is no single best teaching method for every learner, objective, and moment. Select methods from the learner's current knowledge, goal, developmental context, access needs, motivation, and observed response—not from a fixed “learning style.”

## Non-negotiable decision order

1. Protect the learner: privacy, safeguarding, accessibility, and human authority.
2. Hold the mastery criterion constant; do not trade real learning for speed or engagement.
3. Prefer delayed retention and transfer evidence over in-session fluency or satisfaction.
4. Adapt from observed performance and explicit needs, with uncertainty, rather than assigning a permanent learner type.
5. Use the least learner data that can improve the next teaching decision.

## Research boundary

This corpus contains general evidence and synthetic examples only. Never add names, raw conversations, health or disability details tied to a person, credentials, or identifiable progress records. The repository is public.
