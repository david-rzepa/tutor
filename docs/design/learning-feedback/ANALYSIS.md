# Analysis, uncertainty, and issue boundary

The analyzer reports immediate correctness separately from delayed retention and transfer. Learning-speed observations include opportunities and elapsed time; guardrails include voluntary stops, access barriers, excessive challenge, and hint dependence. A faster interaction is not an improvement if delayed learning or guardrails worsen.

Findings group by versioned teaching mechanism and require a minimum distinct-subject cohort. They state confidence, synthetic status, plausible confounders, and the observational/causal boundary. Small groups are suppressed. The initial reference deliberately uses simple transparent rates; a real deployment needs approved cohort thresholds, missing-data handling, age/access fairness analysis, uncertainty calibration, and experiment governance.

The renderer uses only aggregate finding fields and fixed prose to create synthetic reproduction steps, expected learning impact, guardrails, and provenance. Secret/PII/stable-ID patterns and private-source language fail closed. Deduplication uses canonical payload/finding digests. Sending requires the confirmed payload bytes and their exact digest; draft creation never writes externally.
