# Evidence-to-design matrix

Use this as a routing table; load [PRINCIPLES.md](PRINCIPLES.md) and the source before implementation.

| Design claim | Grade | Key moderators / limits | Design consequence | Sources |
| --- | --- | --- | --- | --- |
| Retrieval improves durable retention over extra exposure | strong | prior encoding, feedback, delay, task and outcome | attempt before reveal; retry and schedule | S001, S002 |
| Spacing improves long-term retention | strong | retention horizon, item/learner difficulty, missed sessions | adaptive delayed retrieval, not fixed streaks | S001, S004 |
| Interleaving helps discrimination in some materials | moderate | category similarity, schema, domain | mix confusable cases after foundations | S005 |
| Worked examples help many novices | moderate | expertise, complexity, explanation, fading | model → complete → independent → varied | S006 |
| Feedback effects depend on content/timing | moderate | error, learner, delay, outcome | smallest actionable gap plus retry | S007, S023, S024 |
| Mastery programs can improve achievement | strong | implementation, assessment, time, threshold | fixed outcomes; uncertainty and delayed checks | S008, S019 |
| Fixed learning-style matching improves learning | unsupported | meshing evidence absent; access needs remain real | personalize from outcomes/access, not labels | S003 |
| Self-regulation and autonomy support can help | moderate | age, scaffold, culture, task | teach planning/calibration; bounded choice | S011, S012 |
| UDL helps identify/remediate barriers | policy/framework | implementation efficacy must still be tested | accessible options with unchanged construct | S010 |
| Flow is associated with learning/performance | moderate association | mostly correlational; measures vary | optimize conditions only beneath mastery/well-being | S031, S032 |
| ITS can improve outcomes | moderate | system, comparison, domain, implementation | reuse ITS architecture; verify local outcomes | S028 |
| Generative tutors can help or harm | emerging | guardrails, grounding, subject, age, unassisted test | pedagogical harness, human escalation, unaided evaluation | S020, S021, S022 |
| Knowledge tracing summarizes uncertain evidence | moderate technical basis | calibration, interpretability, dataset shift | versioned estimates; never equate probability with truth | S018, S019 |
| Task-based and corrective-feedback approaches support L2 learning | moderate | proficiency, feedback type, setting, target | meaningful interaction plus selective correction | S023, S024, S025 |
| Young-child digital design must be caregiver/health bounded | policy/guidance | age, purpose, co-use, total routine | real-world/co-use first; no infant solo tutor | S014, S030 |
| Child/learning analytics require rights and privacy governance | policy + moderate review | jurisdiction, data, stakeholder, deployment | minimization, authority, isolation, correction/deletion | S013, S015, S016, S026, S027 |
