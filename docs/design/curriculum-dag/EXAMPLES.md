# Synthetic cross-domain examples

These are deliberately small and use no real learner records.

## Science: predict simple systems

```text
identify parts ─┐
               ├→ trace relationships → predict one change → explain feedback
read a diagram ┘                         ↘ optional: design a test
```

`predict one change` requires both a parts route (`identify parts` OR valid placement) and retained `trace relationships`. A tiny predict/choose/explain card can gather provisional evidence; delayed transfer uses a different system. The graph remains domain content; the assistant template remains generic.

## Music: keep and transform rhythm

```text
steady pulse → reproduce short pattern ─┐
                                       ├→ transform pattern → ensemble task
read simple rhythm symbols ─────────────┘
```

An adult may choose an audio/tap route or visual/keyboard sequence route when rhythm production—not a particular motor action—is the construct. `read symbols` is required for the notation goal, not for every rhythm route. This avoids forcing a visual prerequisite into an auditory/motor objective.

## Everyday mathematics: compare quantities

```text
interpret quantity → compare same-unit quantities → convert representations
                                         └────────→ estimate and justify
```

A learner with strong diagnostic evidence may waive the first node for this curriculum, with recheck expiry. Classification cards can test comparison; ordering cards can test estimation. Transfer requires a novel practical context, not more identical items.

## Young child / caregiver route

A pre-reader’s graph uses caregiver-authorized, observable capabilities and very few visible nodes. The UI presents a simple “now / later / grown” path with pictures plus spoken/printable alternatives; the underlying graph/evidence remains exact. The caregiver controls profile generation, records, pause, and deletion. No streaks, open agent chat, or raw recordings are required.

## Version-change example

If `trace relationships` proves too broad, graph v4 supersedes it with `identify direction` and `follow one link`. Prior evidence remains on the old node; an explicit mapping may provisionally seed the new nodes with low confidence, followed by efficient checks. The map explains the refinement instead of showing unexplained progress loss.
