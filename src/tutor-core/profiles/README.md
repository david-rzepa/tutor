# Private profiles and onboarding

Synthetic reference implementation of the reviewed authority/profile boundary.

- explicit, versioned authority with accessible notice and exact capability/data scope;
- default denial for unknown, stale, ambiguous, or unverified relationships;
- immutable per-user profile history with inspect, correction, export, and revocation;
- validated version round-trips through the trusted portable workspace repository;
- access settings and hypotheses without diagnosis or fixed learning-style labels;
- single observations and access/model failures cannot silently lower knowledge state;
- assistants receive only an opaque activity slice, never identity, authority history, goals, or cross-user data.

The implementation contains no real profile source, provider sharing, identity verification, legal-age constant, diagnosis, transcript, biometric, or public-output path.
