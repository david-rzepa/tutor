# Activity taxonomy

Select an assistant by the mental operation and evidence need. Representation preferences may inform choice among sound options; they are not fixed learner types. Preserve the target construct when offering an accessible route.

| Mechanism | Useful assistant patterns | Evidence produced | Avoid when |
|---|---|---|---|
| Initial encoding / worked example | step explorer, annotated demonstration, listen-and-notice, example/non-example sorter | attention checks, explanation choices, first guided step | learner already demonstrates fluent unaided performance |
| Retrieval | flash prompt with production, picture-to-word, listen-and-recall, reconstruction | unaided/cued response, latency, confidence, error code | content was never encoded or recall demand is not the target and creates an access barrier |
| Discrimination / interleaving | minimal-pair detector, classify-and-contrast, error hunt, choose-the-rule | confusions between categories, contrast-specific latency | categories are not yet separately understood |
| Procedural practice | sequence builder, simulator, constrained sandbox, worked-step fading | step correctness, strategy, help use, recovery | authentic consequences cannot be safely simulated |
| Explanation / mental model | predict-observe-explain, causal map, teach-a-character | prediction, explanation rubric, revision | automated rubric cannot safely interpret open production |
| Transfer | novel scenario, role-play, goal-directed simulation, create-and-test | application under changed surface/context, rubric dimensions | foundational knowledge is absent or variation changes the construct |
| Language interaction | information gap, choice-to-speech/text, dialogue repair, pronunciation contrast | meaning achieved, target-form use, repair, selective error patterns | unsafe speech processing, inaccessible modality, or unconstrained social simulation |
| Metacognition | confidence wager without points, error pattern review, plan-then-check | calibration, chosen strategy, correction | reflection overhead would interrupt productive work |

## Composition rules

- One activity has one visible proximal goal and usually one primary mechanism.
- Mini-game aesthetics serve clarity and meaningful consequence. Points, streak pressure, loot loops, artificial scarcity, and endless play are not teaching mechanisms.
- Require a learner action before reveal when retrieval is intended; feedback must alter the next attempt.
- Use short rounds, varied meaningful contexts, and an explicit ending. Schedule later retrieval instead of prolonging the current session.
- Templates declare input modalities, accessible equivalents, scoring limits, generation slots, fallback content, evidence schema, and prohibited uses.
