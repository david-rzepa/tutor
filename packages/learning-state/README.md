# Learning state

Pure, deterministic projection and readiness functions over `@tutor/curriculum-model` contracts.

The explicit-rules v1 model separates evidence from inference, requires multiple varied independent items before provisional progress, requires declared delayed evidence for retention, and requires independent novel-context evidence for transfer. Later contradiction or an expired review horizon produces `needs_review`; engagement and completion are never mastery evidence.

All supplied events must match one opaque user, curriculum, and immutable graph version. Cross-scope reuse requires `importEvidence` with explicit authority, semantic compatibility, provenance, and uncertainty reduction.
